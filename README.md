## 💡 为什么需要这个项目？

几乎每个重度网民、开发者和研究者的收藏夹里，都堆积着几百个多年未打开的陈年链接。在尝试用 AI 或传统扩展整理书签时，往往会踩入三大深坑：

1. **AI 自动语义聚类的灾难**：
   书签是人类的**空间记忆**与**私人业务上下文**（例如：为了买外链而在 SEO 目录下存放了虚拟信用卡支付工具）。一旦让大模型根据通识大词重归类，大模型会把支付工具生硬塞进别的目录，人类几十年的空间肌肉记忆瞬间被切断。
2. **传统死链检测工具的失明**：
   传统扩展只检查 HTTP 状态码是否为 200，对以下**80% 的伪存活与毒性死链**彻底瞎眼：
   - **域名过期被黑灰产抢注**：原本是正经电商工具，现已变成 91成人视频、AOA 赌球博彩或盗版影视站群（HTTP 状态码依然是 200！）；
   - **SSL 证书域名不匹配**：在浏览器打开时直接弹红屏隐私拦截警告（`ERR_CERT_COMMON_NAME_INVALID`）；
   - **HTML 标题与正文伪装 403/404**：HTTP 状态行返回 200，但实际页面直接渲染 `<title>403 Forbidden</title>` 或内嵌博彩跳转脚本；
   - **Cloudflare 致命解析错误**：如 `Error 1000: DNS points to prohibited IP`。
3. **Chromium 云同步（Sync）反向覆写死锁**：
   现代浏览器开启账号云同步（如 Edge Sync / Chrome Sync）后，离线直接改写磁盘上的 `Bookmarks` JSON 文件属于无效操作。云同步引擎遵循 **「Remote parent wins」** 规则，启动联网瞬间会强制拉取云端旧版本完整覆盖本地修改。

## 🎯 核心工程原则

- **原则 1：绝对零物理删除（数据总量严格守恒）**  
  治理前后书签总数 100% 严格一致。不可访问的站点统一移入隔离区，坚决不物理删除任何一条网址。
- **原则 2：绝对空间记忆守恒（严禁 AI 重新发明大分类）**  
  保留用户原有的各级业务分类与目录层级，严禁跨目录随意打散重组。
- **原则 3：组内频次浮顶（高频自然置顶）**  
  读取浏览器本地真实历史库（`History` SQLite 中的 `visit_count`），**仅在每个原有文件夹内部**将高频访问项置顶，长期未点击项自然沉底。
- **原则 4：死链客观二元分级隔离**  
  在书签栏末尾设立 `⚠️ 待核实_疑似失效`，按客观原因细分 6 个子目录（连接重置 / 超时 / 伪装403 / 灰黑产劫持 / 证书异常 / 空响应）。用户对确定死亡项随时可一键整包清空，零心理负担。
- **原则 5：宿主内部特权管道注入（防云同步回滚）**  
  通过浏览器内部管理页（`edge://favorites` 或 `chrome://bookmarks`）调用原生特权接口（`chrome.bookmarks.move`），让每次移动直接作为原生事件上报云端同步引擎，确保永久生效。

## 🚀 极速上手：两种使用方式

### 方式 A：Agent 一键自执行配方（最推荐）

如果你正在使用拥有本地终端执行权限的 AI Agent（如 **Codex、Claude Code、Cursor、Devin** 等）：

1. 打开 [PROMPT.md](PROMPT.md)；
2. 完整复制全篇内容，直接发送给你的本地 Agent；
3. Agent 会自适应检测你的浏览器、探测本地代理端口、确认保护白名单，并在 1 分钟内自动完成全套无损体检与就地归档。

### 方式 B：独立 Python 脚本运行（无大模型依赖）

如果你只想纯本地脚本快速扫描，可以直接使用本项目内置的免依赖探针：

```bash
# 运行深度探测与体检报告生成
python3 scripts/bookmark_audit.py --browser edge --proxy http://127.0.0.1:7897
```
